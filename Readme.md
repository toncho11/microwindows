Home of NXDSKTOP - a x86 graphical desktop environment for [Nano X](https://github.com/ghaerr/microwindows) and its companion applications for the [ELKS](https://github.com/ghaerr/elks) operating system. NXDSKTOP can run on the oldest x86 machine - the IBM 5150/5160, but at least an 8 MHz machine such as the Amstrad 1640 is recommended. A 286, 386 or 486 will be even better. A VGA video card is required.

<img width="640" height="480" alt="nxdsktop" src="https://github.com/toncho11/microwindows/blob/master/screenshots/nxdsktop_1.1_img1.png" />

* nxdsktop - provides a graphical desktop environment coupled with a few functions from a file manager and system commands. Nxdsktop is auto-updating the amount of available free/total memory in the lower right corner. This allows you to start several nx applications, but you are always aware how far you can go before you run out of memory. You can both view an image and access a file by only using the mouse. Nxdsktop uses nxselect and nxmsg to provide user visual dialogs.
  * How to use nxdsktop? Check the [online help/documentation](https://github.com/toncho11/microwindows/wiki) for more details
  * You can also learn more about its [design principles](https://github.com/toncho11/microwindows/wiki/Design-principles)
* nxjpeg - jpg image viewer with 3 color modes, 2 render modes and 3 smoothing modes. Images might need to be optimized for ELKS (size, resolution, etc). This is explained in the source file of nxjpeg
* nxselect - a graphical file selector app
* nxmsg - an app that displays a message box text with title. Text can be alighed left/center/right

Actual code development is done in branches. Main branch is https://github.com/toncho11/microwindows/tree/start_menu
