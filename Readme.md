Home of NXDSKTOP - a graphical desktop environment for [Nano X](https://github.com/ghaerr/microwindows) and its companion applications for the [ELKS](https://github.com/ghaerr/elks) operating system. NXDSKTOP can run on the oldest x86 machine - the IBM 5150/5160, but at least an 8 Mhz machine such as the Amstrad 1640 is recommended.

* NXDSKTOP - an application that provides graphical desktop environment coupled with a few functions from a file manager and system commands. NXDSKTOP is auto-updating the amount of available free/total memory in the lower right corner. This allows you to start several nx applications, but you are always aware how far you can go before you run out of memory. You can both view an image and access a file by only using the mouse.
  * How to start NXDSKTOP? Check [running Nano X on ELKS](https://github.com/ghaerr/elks/wiki/Nano%E2%80%90X). Usually the main problem is configuring a serial mouse on ttyS0 or ttyS1. You also have a [Troubleshooting section](https://github.com/ghaerr/elks/wiki/Nano%E2%80%90X#troubleshooting)
  * check the [online help](https://github.com/toncho11/microwindows/wiki) for more details
* nxjpeg - jpg image viewer with 3 color modes, 2 render modes and 3 smoothing modes. Images might need to be optimized for ELKS (size, resolution, etc). This is explained in the source file of nxjpeg.
* nxselect - a graphical file selector app
* nxmsg - displays a message box app with title and text 

Actual code development is done in branches. Main branch is https://github.com/toncho11/microwindows/tree/start_menu
