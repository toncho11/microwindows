Home of several applications for [Microwindows / Nano X](https://github.com/ghaerr/microwindows) for [ELKS](https://github.com/ghaerr/elks)
<img width="640" height="480" alt="nxdsktop" src="https://github.com/user-attachments/assets/c3727980-050c-4263-b11a-cea87bff5dcf" />
* nxdsktop - nxdsktop tries to be a complete (as much as possible) desktop environment coupled with a few functions from a file manager and system commands. Nxdsktop is auto-updating the amount of available free/total memory in the lower right corner. This allows you to start several nx applications, but you are always aware how far you can go before you run out of memory. You can both view an image and access a file by only using the mouse.
* nxjpeg - jpg viewer with several color, render and smoothing modes. Images might need to be optimized for ELKS (size, resolution, etc). This is explained in the source of nxjpeg.
* nxselect - a graphical file selector

Actual code development is done in branches. Main branch: https://github.com/toncho11/microwindows/tree/start_menu
