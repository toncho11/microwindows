Home of nxdsktop for [Microwindows / Nano X](https://github.com/ghaerr/microwindows) for [ELKS](https://github.com/ghaerr/elks and its companion applications.

<img width="640" height="480" alt="nxdsktop" src="https://github.com/user-attachments/assets/c3727980-050c-4263-b11a-cea87bff5dcf" />
* nxdsktop - a desktop environment coupled with a few functions from a file manager and system commands. Nxdsktop is auto-updating the amount of available free/total memory in the lower right corner. This allows you to start several nx applications, but you are always aware how far you can go before you run out of memory. You can both view an image and access a file by only using the mouse.
  * check the [online help](https://github.com/toncho11/microwindows/wiki) for more details
* nxjpeg - jpg image viewer with several color(3), render(2) and smoothing modes(3). Images might need to be optimized for ELKS (size, resolution, etc). This is explained in the source file of nxjpeg.
* nxselect - a graphical file selector
* nxmsg - displays a message box with title and text 

Actual code development is done in branches. Main branch is https://github.com/toncho11/microwindows/tree/start_menu
